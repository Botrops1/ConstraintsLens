Tips & tricks

Selecting

  • Click a row — selects that constraint's entities in the viewport.
  • Click the icon at the left of a row — selects the constraint object itself.
  • Click an entity chip — filters the list to it and selects it on the canvas.
  • Select on the canvas — matching rows highlight and scroll into view on their own; no button needed.
  • ⌕ Zoom — when on, the camera follows each selection.

Reading the list

  • Hover the type name — shows the full description and the Fusion API type, e.g. Tangent — Line 3 ⌒ Arc 1 and TangentConstraint. Both stay searchable even though the row shows only the type.
  • A dimmed, dashed chip marked hidden is geometry Fusion doesn't draw — internal control points from an offset or spline. The row still works: clicking it selects that entity.
  • Endpoint joins are implicit — two curves sharing one point, not a real constraint. They carry a ⊘ and no checkbox, because there is nothing for Fusion to delete.
  • Section headers show (N of M) while a filter is active.

Editing

  • Double-click a row — opens Fusion's own edit dialog for it.
  • Pencil icon on a dimension — edit the expression inline. Enter commits, Esc cancels.
  • Checkboxes + Delete N — bulk delete; Clear unchecks them all. Ctrl+Z undoes the whole sketch edit, not one row.

Finding

  • Filter box — matches constraint type, label and entity names, so Line 3 finds everything touching Line 3.
  • Clicking one entity on the canvas sets the filter for you — that's why the list sometimes narrows on its own. The ✕ beside the box clears it.
  • Show u/c — runs Fusion's Show Underconstrained; results arrive as clickable chips.
  • Section header — the chevron collapses it, the checkbox selects everything in it.

Sizing the panel

  • Drag a grip strip — the one under Selected: and the one above Properties of selected: resize those panes. Double-click either one to reset it.
  • ⇕ button — cycles the docked height: 50% / 75% / full column. The strip along the very bottom edge sets anything in between. Both apply on release and flicker once — Fusion refuses to resize a docked palette in place.
  • Dock or float by dragging the palette's own title bar; Fusion remembers where you put it.

Housekeeping

  • ☀ / 🌙 — switches theme. Theme and pane sizes are remembered between sessions.
  • Refresh — rarely needed; the list re-scans itself after every sketch edit. Use it if the palette looks stale after minimising and restoring it.
  • The palette follows sketch-edit mode — it hides when you leave a sketch and returns on the next one.
  • Close it with ✕ to stop it reappearing until you click Constraint Lens in the Sketch toolbar again.
